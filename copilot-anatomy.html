Six primitives, one coherent system

Copilot's customisation stack works in layers: instructions are always on, skills load when relevant, prompts are invoked manually, chatmodes set a persona for a session, agents run autonomously in chains, and hooks enforce hard policies.

A governance layer — asset manifest, model compatibility matrix, CI evaluation gates, and changelog — ensures quality and ownership as the setup evolves.
